# Employee Management API

This project is a small full-stack employee management application built with Spring Boot, MySQL, JDBC, and a simple HTML/CSS/JavaScript frontend.

It supports CRUD operations for employee records and includes basic role-based protection for admin actions.

## Features

- View all employees
- Search employee by ID
- Search employee by First Name
- Create a new employee
- Update employee salary
- Delete employee by ID
- Basic admin authorization for protected actions
- Simple frontend using HTML, CSS, and JavaScript

## Tech Stack

- Java
- Spring Boot
- Spring Security
- MySQL
- JDBC
- HTML
- CSS
- JavaScript

## API Endpoints

### Public Endpoints

`GET /employees`

Returns all employees.

`GET /employees/id/{id}`

Returns one employee by ID.

`GET /employees/name/{name}`

Returns employees by First Name.


### Admin-Protected Endpoints

These endpoints require admin credentials.

`POST /employees`

Creates a new employee.

Example request body:

```json
{
  "name": "Julian",
  "lastname": "Mejia",
  "dob": "1990-05-10",
  "salary": 3500.0
}
```

`PUT /employees/{id}/salary`

Updates the salary of an employee.

Example request body:

```json
{
  "salary": 5000.0
}
```

`DELETE /employees/{id}`

Deletes an employee by ID.

## Demo Admin Credentials

For learning/demo purposes, this project uses an in-memory admin user:

```text
Username: admin
Password: admin123
```

Protected actions from the frontend will prompt for these credentials.

> Note: This authentication setup is for learning purposes only and is not production-ready.

## Database Setup

Create a MySQL database named `employee_db`:

```sql
CREATE DATABASE employee_db;
USE employee_db;
```

Create the `employees` table:

```sql
CREATE TABLE employees (
    id INT AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(100),
    last_name VARCHAR(100),
    date_of_birth DATE,
    salary FLOAT
);
```

Notes:

- `date_of_birth` should use the format `YYYY-MM-DD`.
- The `id` field is auto-generated by MySQL.

## Configuration

Copy:

```text
src/main/resources/application-example.properties
```

to:

```text
src/main/resources/application.properties
```

Then update the database credentials:

```properties
spring.datasource.url=${DB_URL:jdbc:mysql://localhost:3306/employee_db}
spring.datasource.username=${DB_USERNAME:your_username}
spring.datasource.password=${DB_PASSWORD:your_password}
```

The real `application.properties` file should not be committed to GitHub.

## How to Run

1. Clone the repository.
2. Create the MySQL database and table described above.
3. Create `application.properties` from the example file.
4. Start the Spring Boot application.
5. Open `frontend/index.html` in a browser.
6. Use the frontend to view, create, update, or delete employees.

## Notes

- GET requests are public.
- POST, PUT, and DELETE requests require admin authorization.
- The frontend uses JavaScript `fetch()` to communicate with the Spring Boot API.
- The backend uses JDBC and a DAO layer to interact with MySQL.
- CORS is configured to allow the local frontend to communicate with the backend.
